## 短简介（约 100 字，适合群聊 / 论坛 / 朋友圈）

DSH 启动器是一个 60 KB 的 Windows 小工具，专门解决 DeepSeek Harness（dsh）Web 界面必须常开命令行窗口的问题。双击后服务在后台静默运行，托盘留一枚鲸鱼图标：右键可打开界面、重启、停止、勾选开机自启，服务崩了会自动拉起，输出全部写入日志。用系统自带的 .NET Framework 编译，不需要装任何运行时。

## 完整简介

### 痛点

DeepSeek Harness 的 Web 界面是本地服务，启动方式是在命令行敲：

```bash
npx @deepseek-ai/dsh web
```

三个麻烦随之而来：

1. **窗口得一直开着** —— 手滑关掉，服务立刻停，正在跑的任务全断
2. **占着任务栏** —— 一个只为维持进程存活的窗口，却要占一个位置
3. **开机得手动来一遍** —— 每次重启电脑都要重新开命令行、敲命令、开浏览器

### 它做什么

DSH 启动器把这些收进一个托盘图标里。双击一次，`dsh web` 以隐藏窗口方式在后台启动，界面照常通过浏览器访问：

```
双击 exe → 托盘出现鲸鱼 → 右键「打开 Web UI」→ 正常使用
```

它只做三件事：**拉起服务、托管进程、提供开关**。不修改 dsh 的任何代码，行为与手敲命令完全一致。

### 能力一览

| 能力 | 说明 |
|---|---|
| **无黑窗** | 编译为 GUI 子系统，全程不弹控制台 |
| **托盘管理** | 打开界面 / 重启 / 停止 / 看日志 / 退出 |
| **开机自启** | 写当前用户注册表，免管理员权限，一次勾选永久生效 |
| **崩溃自愈** | 服务异常退出自动重启，最多连续 3 次，之后弹气泡提醒看日志 |
| **日志落盘** | stdout / stderr 全量写入带时间戳的文件，出问题能回溯 |
| **单实例** | 重复双击不会开第二个，已运行则直接识别 |
| **可配置** | 端口、工作区目录、是否自动重启，都写在 ini 里 |
| **零运行时依赖** | 60 KB 单文件，Windows 10/11 自带 .NET Framework 4.x 即可运行 |

### 适合谁

- **每天用 DSH 写代码的人** —— 不用再维护一个命令行窗口
- **把 DSH 当常驻服务用的人** —— 开机即用，崩了自愈
- **想把它塞进自己工作流的人** —— 提供 `--port` / `--workdir` / `--selftest` 等命令行参数

### 技术特点

- **单文件源码**：一个 `DshWebLauncher.cs`（约 585 行），C# 5 语法
- **零 SDK 依赖**：直接用 Windows 自带的 `csc.exe` 编译，不需要 .NET SDK 或 Visual Studio
- **图标双嵌入**：Win32 资源（资源管理器图标）+ .NET 资源（托盘图标按 DPI 取尺寸）
- **CI 自动发版**：GitHub Actions 上编译、校验图标载荷、冒烟测试，打 tag 自动建 Release

## English

**DSH Launcher** — a 60 KB tray app that turns `dsh web` (DeepSeek Harness) into a silent background service on Windows.

Double-click once and the server runs hidden; a whale icon in the system tray gives you open / restart / stop / autostart / logs. It restarts the service automatically if it crashes, and writes everything to a log file. Built with the .NET Framework compiler that ships with Windows — no SDK, no runtime install, no console window.

```powershell
# what it actually runs, in the background
node "<dsh>\lib\bin.js" web --port 3080 --no-open
```
