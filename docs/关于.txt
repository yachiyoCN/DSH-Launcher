========================================
  DSH 启动器  ·  关于
========================================

名称：DSH 启动器（DSH Web Launcher）
版本：1.0.1
类型：Windows 托盘后台启动工具
体积：67 KB（单文件，无安装程序）
平台：Windows 10 / 11 (x64)


----------------------------------------
  适用端（重要）
----------------------------------------

【适用】DeepSeek Harness 的 Web 版
        服务以 `dsh web` 启动，界面在浏览器中访问：
        http://127.0.0.1:3080 （端口可在配置中修改）

【不适用】DeepSeek Harness Desktop 桌面客户端
        桌面端是 Electron 应用，自带托盘图标、开机自启和窗口管理，
        本身就是常驻程序，不需要也不应该用本工具托管。
        另外它的 desktop profile 由客户端独占，CLI 无法接管，
        本工具即使强行启动也拿不到它。

  一句话：给「浏览器里用的 dsh web」用的，不是给桌面客户端用的。

----------------------------------------
  关于这个程序
----------------------------------------

把 `dsh web` 从"必须开着 CMD 窗口"变成"托盘常驻后台服务"。

双击一次，服务静默运行，托盘留一枚鲸鱼图标；
右键即可打开界面、重启、停止、开机自启、看日志、查看关于。

技术上它只是把下面这条命令以隐藏窗口方式跑起来：

    node "<dsh>\lib\bin.js" web --port 3080 --no-open

所以和服务有的一切行为，与你在命令行里手敲完全一致。
