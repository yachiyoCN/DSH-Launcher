# DSH 启动器 · 使用说明

> 把 `dsh web` 变成托盘后台服务，从此不用再挂一个 CMD 黑窗。

![托盘图标：鲸鱼](https://img.shields.io/badge/%E6%89%98%E7%9B%98%E5%9B%BE%E6%A0%87-%E9%B2%B8%E9%B1%BC-1f2937)

---

## 一、简介

### 它解决什么问题

平时启动 DeepSeek Harness 的 Web 界面，要开一个命令行窗口敲：

```bash
npx @deepseek-ai/dsh web
```

这个窗口**一直得一开着**，一关服务就停；窗口本身还占着任务栏，误关一下全部崩掉。

**DSH 启动器**就是把这个过程包起来：双击一次，服务在后台静默跑，托盘留一个小鲸鱼图标，随时右键管理。

### 适用端（先看这个）

> **本工具只管 `dsh web` —— 也就是浏览器里用的那个版本。**

| | 端 | 是否适用 | 原因 |
|---|---|---|---|
| ✅ | **DeepSeek Harness Web 版**（`dsh web`） | **适用** | 服务跑在本地，需要浏览器访问 `http://127.0.0.1:3080`，本质是个"得一直开着的进程"，正适合托管 |
| ❌ | **DeepSeek Harness Desktop 桌面客户端** | **不适用** | 它是 Electron 应用，**本身就常驻托盘**、自带开机自启和窗口管理，不需要再套一层；而且它的 `desktop` profile 由客户端独占，CLI 根本无法接管 |

如果你用的是桌面客户端，直接用它自己的托盘图标和设置里的开机自启就行，**不要用本工具**。

### 特性

| 能力 | 说明 |
|---|---|
| **无黑窗** | 编译为 GUI 子系统程序，全程不弹控制台窗口 |
| **托盘常驻** | 小鲸鱼图标，右键即出菜单 |
| **开机自启** | 一次勾选，开机自动拉起，无需手动双击 |
| **崩溃自愈** | 服务异常退出后自动重启，最多连续 3 次 |
| **日志落盘** | 服务输出全部写入日志文件，出问题可回溯 |
| **单实例** | 重复双击不会开第二个，已运行则直接复用 |
| **零依赖** | 单个 60 KB 的 exe，不需要安装 Python/Node 运行时以外的任何东西 |
| **可配置** | 端口、工作区目录都能通过配置文件改 |

### 系统要求

- Windows 10 / Windows 11（x64）
- **.NET Framework 4.x**（Win10 1903 以后系统自带，无需额外安装）
- 已经装好 **Node.js** 和 **DeepSeek Harness**（`dsh` 命令可用）

## 二、快速开始

### 第 1 步：确认 dsh 可用

按 `Win + R` 输入 `cmd`，敲：

```bash
dsh --version
```

能打印出版本号即可。提示"不是内部或外部命令"说明还没装 DSH。

### 第 2 步：关掉旧的 CMD 窗口（可选）

如果你正开着一个 `dsh web` 的命令行窗口，建议先关掉。不关也不会出错 —— 启动器会检测到端口已占用，直接进入"已在运行"状态，不会重复启动。

### 第 3 步：双击 `DSHWebLauncher.exe`

托盘区出现**小鲸鱼图标**就成功了。首次启动会自动拉起 `dsh web`，大约 5~15 秒后服务就绪。

### 第 4 步：打开界面

**双击托盘图标**，或右键 → **打开 Web UI**，浏览器会自动跳转到 `http://127.0.0.1:3080/`。

### 第 5 步：设置开机自启（推荐）

右键托盘图标 → 勾选 **开机自启**。以后开机自动在后台运行，你只管用。

---

## 三、托盘菜单详解

| 菜单项 | 作用 |
|---|---|
| **状态：运行中 PID xxxx · 端口 3080** | 只读，随时看服务是否活着 |
| **打开 Web UI** | 用默认浏览器打开界面 |
| **重启服务** | 结束当前进程树后重新拉起（改完配置后用这个） |
| **停止服务** | 结束 `dsh web` 及其所有子进程，但托盘图标保留 |
| **开机自启** | 勾选/取消，写入当前用户的注册表启动项，**不需要管理员权限** |
| **打开日志目录** | 直接打开日志文件夹 |
| **关于** | 查看版本、适用端说明、作者邮箱与仓库地址 |
| **退出** | 停止服务并退出托盘程序（这是唯一会彻底关掉的入口） |

> 关掉托盘程序 = 服务也停。如果希望服务常驻，用「停止服务」而不是「退出」。

## 四、配置

配置文件位置：

```
%LOCALAPPDATA%\DSHWebLauncher\settings.ini
```

在文件资源管理器地址栏粘贴 `%LOCALAPPDATA%\DSHWebLauncher` 可直达。

### 默认内容

```ini
# DSH Web Launcher 配置（改完重启托盘程序生效）
NodePath=C:\Program Files\nodejs\node.exe
DshBin=C:\Users\你的用户名\AppData\Roaming\npm\node_modules\@deepseek-ai\dsh\lib\bin.js
Profile=web
Port=3080
WorkDir=C:\Users\你的用户名\Documents\deepseek-harness\default-workspace
AutoRestart=1
```

### 字段说明

| 字段 | 说明 |
|---|---|
| `NodePath` | node.exe 的完整路径 |
| `DshBin` | dsh 的主入口 `lib/bin.js` 完整路径 |
| `Profile` | profile 名（一般保持 `web`） |
| `Port` | Web 界面端口，默认 3080。如果被占用就改成 3081、8080 等 |
| `WorkDir` | dsh 的工作区根目录，新建会话时的默认文件夹 |
| `AutoRestart` | `1` 开启崩溃自动重启，`0` 关闭 |

> **改完配置要重启托盘程序**（右键 → 退出，再双击 exe）。

## 五、命令行参数（进阶）

除了双击，也支持命令行调用，方便写脚本或做快捷方式：

```powershell
DSHWebLauncher.exe                      # 正常启动（托盘常驻）
DSHWebLauncher.exe --port 3081          # 指定端口启动
DSHWebLauncher.exe --workdir D:\code    # 指定工作区
DSHWebLauncher.exe --enable-autostart   # 开启自启（静默执行，适合脚本）
DSHWebLauncher.exe --disable-autostart  # 关闭自启
DSHWebLauncher.exe --autostart-status   # 查询自启状态
DSHWebLauncher.exe --status             # 打印当前配置
DSHWebLauncher.exe --selftest           # 自检：拉起→等端口→报告→退出（不常驻）
```

`--selftest` 特别适合排查问题：它会打印 `port_open=1` 或 `0`，并附上日志尾部，跑完自动清理，不留进程。

## 六、常见问题

**Q1：双击后托盘没有鲸鱼图标？**

先看任务管理器里有没有 `DSHWebLauncher.exe`：

- **有进程但没图标** → 可能是资源管理器托盘区折叠了，点向上的小箭头展开看看
- **进程一闪就没了** → 用命令行跑一次 `DSHWebLauncher.exe --selftest`，看输出的日志尾部报什么错

**Q2：托盘显示"已在运行（外部实例，端口 3080）"？**

说明 3080 已经被别的程序（多半是你之前开着的 CMD 窗口）占用了，启动器不会重复启动。关掉那个窗口，然后右键 → 重启服务。

**Q3：开机自启没生效？**

1. 右键托盘 → 确认「开机自启」是勾选状态
2. 按 `Win + R` 输入 `shell:startup`，看里面有没有快捷方式（本程序用的是注册表方式，不一定在这里）
3. 按 `Win + R` 输入 `regedit`，检查：
   ```
   HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run
   ```
   里面应该有 `DSHWebLauncher` 一项，值是 exe 的完整路径
4. **最常见原因：exe 被移动或重命名过** → 重新勾一次自启即可

**Q4：改了端口，浏览器还开旧地址？**

菜单「打开 Web UI」会按当前配置的端口打开。改完 `settings.ini` 需要**重启托盘程序**才生效。

**Q5：日志在哪？**

```
%LOCALAPPDATA%\DSHWebLauncher\logs\
```

文件名形如 `web-20261022-151152.log`，右键菜单「打开日志目录」可直达。

**Q6：启动时会不会自动弹浏览器？**

不会。启动器给 `dsh web` 传了 `--no-open`，避免开机自启时突然弹一个浏览器窗口。要看界面请用托盘菜单。

**Q7：怎么彻底卸载？**

1. 右键托盘 → 取消勾选「开机自启」
2. 右键托盘 → 退出
3. 删除本文件夹
4. 删除 `%LOCALAPPDATA%\DSHWebLauncher`（配置和日志）

## 七、工作原理（给好奇的人）

启动器做的事情其实很简单：把

```bash
node "<dsh安装目录>\lib\bin.js" web --port 3080 --no-open
```

这条命令以**隐藏窗口**方式启动，标准输出/错误重定向到日志文件，然后用 WinForms 的 `NotifyIcon` 在托盘上挂一个图标来管理这个进程。

所以它和你在 CMD 里手敲命令跑起来的是**同一个东西**，只是外面套了层便于管理的壳。

## 八、从旧副本迁移

如果你之前把 exe 放在别处（比如桌面根目录）并且**它正在运行**，那个文件会被占用、删不掉。文件夹里的 `一键迁移.bat` 会一次性处理：

1. 停止正在运行的旧启动器
2. 删除桌面根目录的旧 exe
3. 从本文件夹启动新版

> 双击运行即可。它会先关掉 dsh 服务，脚本跑完后重新打开浏览器界面就行。
> 跑完记得右键托盘图标 → 勾选「开机自启」，让自启指向新位置。

## 九、注意事项

- 本程序**只负责启动和管理**，不包含 DeepSeek Harness 本体
- 卸载本程序不会影响你已安装的 DSH 和会话数据
- 自启写在**当前用户**注册表下，不需要管理员权限，也不会影响其他账户
- 如果公司电脑装了安全软件拦截自启注册表写入，可能会静默失败，请自行放行
